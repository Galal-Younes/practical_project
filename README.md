# Practical Project
 
A responsive, multi-section business landing page built with **HTML** and **CSS**. The project was built to practice structuring a full marketing-style website: presenting a business's features, articles, gallery, team, testimonials, and hosting/pricing plans in a clean, organized layout.
 
## Sections Included
 
- Landing / hero area
- Features overview
- Team showcase
- Photo gallery
- Client testimonials
- Articles / blog preview
- Hosting & pricing plans
- Stats highlights
## Tech Stack
 
- **HTML5** — semantic page structure
- **CSS3** — custom styling (`style.css`, `normalize.css` for cross-browser consistency)
- **Font Awesome** — icon set
## Project Structure
 
```
pracitcal_project/
  index.html
  css/
    style.css
    normalize.css
    all.min.css
  images/
  webfonts/
```
 
## Getting Started
 
Simply open `pracitcal_project/index.html` in any modern browser — no build step or dependencies required.
 
## What I Practiced
 
- Structuring a multi-section landing page with clean, semantic HTML
- Using `normalize.css` to keep styling consistent across browsers
- Organizing a real-world asset structure (images, fonts, icons)
